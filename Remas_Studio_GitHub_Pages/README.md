# Remas’s Studio for GitHub Pages

1. Extract this ZIP.
2. Upload its contents directly to the root of the main branch. The file list should show index.html and the art folder side by side.
3. In Settings → Pages, select Deploy from a branch, main, and /(root). Save and wait for the Pages deployment to finish.

This edition includes the gallery, quizzes, exercises, painting tips, and notebook. GitHub Pages serves the static site. For live Groq replies, use the full source package and deploy its server separately. Keep your API key in the backend’s secret settings.
